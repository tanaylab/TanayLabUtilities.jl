Sparse Columns

TanayLabUtilities.SparseColumns — Module

Read the values of some of the rows of the columns of a SparseMatrixCSC .

Reading matrix[row, column] for many rows costs a binary search per row, while walking a whole column visits every stored value of the column, wanted or not. The functions here take the wanted rows as a sorted vector of row indices, and merge it with the sorted rows of each column, galloping forward for each wanted row. This costs about s * log(nnz / s) for s wanted rows and nnz stored values in the column. So it behaves like s binary searches when few rows are wanted, and like a walk of the column when most rows are wanted.

The position of a wanted row is its index in the vector of wanted rows. Callers use it to index their own buffers.

These functions take a plain SparseMatrixCSC . A caller with a lazy matrix converts it once, outside its loop, using plain_array for all of it or matrix[:, columns] for a few of its columns.

TanayLabUtilities.SparseColumns.stored_values_at_rows — Function 
stored_values_at_rows(
    matrix::SparseMatrixCSC,
    column_index::Integer,
    row_indices::AbstractVector{<:Integer},
)

Iterate on the stored values of one column of a sparse matrix , in some of its rows. The wanted row_indices must be sorted in increasing order, with no repetitions. This yields (position, value) for each wanted row that has a stored value, where position is the index of the row in row_indices . Wanted rows that have no stored value (that is, are zero) are skipped. 

using SparseArrays
using TanayLabUtilities.SparseColumns

matrix = sparse([0 1; 2 0; 3 4; 0 5])

@assert collect(stored_values_at_rows(matrix, 1, [1, 3, 4])) == [(2, 3)]
@assert collect(stored_values_at_rows(matrix, 2, [1, 3, 4])) == [(1, 1), (2, 4), (3, 5)]

TanayLabUtilities.SparseColumns.gather_sparse_column! — Function 
gather_sparse_column!(
    destination::AbstractVector,
    matrix::SparseMatrixCSC,
    column_index::Integer,
    row_indices::AbstractVector{<:Integer},
)::Bool

Gather the values of one column of a sparse matrix , in some of its rows, into a dense destination . The wanted row_indices must be sorted in increasing order, with no repetitions. The value of each wanted row is placed in the destination at the row's position in row_indices . Returns whether any of the gathered values is non-zero. 

using SparseArrays
using TanayLabUtilities.SparseColumns

matrix = sparse([0 1; 2 0; 3 4])
destination = Vector{Int}(undef, 2)

@assert gather_sparse_column!(destination, matrix, 1, [2, 3])
@assert destination == [2, 3]

destination = Vector{Int}(undef, 1)
@assert !gather_sparse_column!(destination, matrix, 2, [2])
@assert destination == [0]

TanayLabUtilities.SparseColumns.sum_sparse_columns_per_group! — Function 
sum_sparse_columns_per_group!(
    destination::AbstractMatrix,
    matrix::SparseMatrixCSC,
    row_indices::AbstractVector{<:Integer},
    column_indices_per_group::AbstractVector{<:AbstractVector{<:Integer}},
)::Nothing

Add the sums of groups of columns of a sparse matrix , in some of its rows, into a dense destination . The wanted row_indices must be sorted in increasing order, with no repetitions. The destination has a row per group and a column per position in row_indices . The value of each wanted row in each group is the sum of the row's values in the group's column_indices_per_group . This is added to the destination , which isn't cleared first. 

using SparseArrays
using TanayLabUtilities.SparseColumns

matrix = sparse([1 0 2; 0 3 0; 4 5 6])
destination = zeros(Int, 2, 2)

sum_sparse_columns_per_group!(destination, matrix, [1, 3], [[1, 3], [2]])
@assert destination == [3 10; 0 5]
